# 🏋️‍♂️ Body Performance Analysis & Prediction
### Multi-Model Machine Learning Suite: Classification & Regression

## 📝 Project Overview
This project provides a comprehensive analysis of body performance data using various Machine Learning algorithms. The goal is to predict fitness levels (Classification) and physical performance metrics (Regression) based on biometric data.

## 📂 Project Structure
All project files are located in the root directory for direct access:

### 📊 Datasets
*   `bodyPerformance.csv`: Main dataset used for training and validation[cite: 10].
*   `bodyPerformance_test.csv`: Independent test set for final model evaluation[cite: 10].

### 🤖 Machine Learning Notebooks
The project explores multiple algorithms to compare performance[cite: 1, 10]:
*   **Linear & Regularization:** `Linear Regression.ipynb`, `Regularization_techniques.ipynb`.
*   **Distance-Based:** `KNN Classification.ipynb`, `KNN_Regression.ipynb`.
*   **Tree-Based:** `Decision Tree Classification & Regression.ipynb`.
*   **Advanced Models:** `SVM Classification & Regression.ipynb`, `Neural Network Classification.ipynb`, `Neural Network Regression.ipynb`.

## 🛠️ Implementation Details
*   **Language:** Python[cite: 1, 10].
*   **Libraries:** Pandas, NumPy, Scikit-Learn, Matplotlib, Seaborn[cite: 10].
*   **Preprocessing:** Includes Label Encoding for categorical data and StandardScaler for feature normalization[cite: 10].
*   **Evaluation:** Models are evaluated using Accuracy, Precision, Recall, MSE, and R-squared metrics[cite: 10].

## 🚀 How to Use
1. Clone this repository.
2. Open any `.ipynb` file in Jupyter Notebook or Google Colab[cite: 10].
3. Ensure the `.csv` files are in the same directory as the notebooks to allow proper data loading[cite: 10].
